# Shards v0.1.0 — one vault for you and your agents

Shards is a task manager for humans and AI agents, backed by Markdown files you own.
This first public preview brings the macOS desktop app, command-line tools and stdio MCP
server together over the same local vault. No account is required.

## What you can do

- **Plan your day in the desktop app.** Use Inbox, Today, Upcoming and project views;
  capture tasks with quick add; browse notes, agent memories and scratchpads.
- **Hand work between people and agents.** Assign an owner, claim a task, track its
  delegate, and finish or release it. Dependencies determine which tasks are ready next.
- **Keep recurring work in order.** Tasks support due dates, deadlines, recurrence,
  subtasks, sections and priorities. Finishing a recurring task advances its due date.
- **Work from your terminal or MCP client.** `shards` and `shards-mcp` expose the same
  underlying operations. The CLI provides JSON output and shell completions.
- **Keep your files accessible.** Tasks, notes, memories, scratchpads and assets live
  in five configurable spaces. Built-in search works locally, with optional semantic
  retrieval through `indexed`.

The desktop app refreshes when an agent changes the vault. The CLI and MCP tools also
work independently, without the desktop app running.

## Install

On macOS 13.3 or later, install the desktop app **and** CLI + MCP:

```bash
brew install --cask LennardZuendorf/tap/shards
```

Or install only CLI + MCP:

```bash
brew install LennardZuendorf/tap/shards-cli
```

Then run `shards init` to create your local configuration and vault. To connect an MCP
client, use `shards-mcp` as its command. See the [README](https://github.com/LennardZuendorf/shards/blob/v0.1.0/README.md#first-run)
for configuration and examples.

Direct downloads are attached below:

| Platform | Desktop + bundled tools | CLI + MCP |
|---|---|---|
| Mac, Apple Silicon | `Shards-0.1.0-aarch64-apple-darwin.dmg` | `shards-cli-0.1.0-aarch64-apple-darwin.tar.gz` |
| Mac, Intel | `Shards-0.1.0-x86_64-apple-darwin.dmg` | `shards-cli-0.1.0-x86_64-apple-darwin.tar.gz` |
| Linux, x86_64, glibc 2.35+ | — | `shards-cli-0.1.0-x86_64-unknown-linux-gnu.tar.gz` |

For a direct DMG install, drag Shards to Applications. Both tools are included inside
`Shards.app/Contents/MacOS/`; Homebrew also puts the standalone tools on your PATH.
`SHA256SUMS` and `release-manifest.json` accompany the downloads.

## Before you start

**The Mac app is ad-hoc signed, without Apple Developer ID signing or notarization.**
macOS may block the first launch. After trying to open it, use **System Settings →
Privacy & Security → Open Anyway** only if you trust the source and have verified the
download. See the [installation guide](https://github.com/LennardZuendorf/shards/blob/v0.1.0/docs/releases.md#first-mac-launch).

This is an early desktop preview. Sync, hosted remote MCP, the server application,
Windows packages and a Linux desktop app are still planned. Local task identities are
cooperation conventions between trusted processes, rather than authenticated identities.
CLI and MCP deletes permanently remove files, so keep backups of vaults you care about.
