# Built-in browser visual review

Reviewed by a subagent on 2026-10-28 in the Codex built-in browser. The parent chat's open tab was not navigated. Browser bindings are scoped to each chat, so the subagent opened the same local URL in its own hidden built-in-browser tab. No Yab or native app was used for this review.

Observed at 1280 × 720, 900 × 720 and 720 × 720:

- Renew-domain hover and keyboard-selected rows keep dates, deadline, admin label and Inbox separate from all three action buttons. The captured hover state was confirmed with the actual CSS :hover state.
- Rich metadata wraps without covering other metadata. A title/checkbox first-line offset was found at 900px and corrected: measured center difference 7.5px before, 0.5px after. The final 900px keyboard image includes the correction.
- Folders/Tags tabs switch by pointer and arrow key, with one visible labelled panel. Selecting decisions and launch together shows Pricing Decision only, with the correct 1 file count. Dark 900px and 720px tabs remain readable.
- Sidebar trays have measured 10px gaps. Nested project/label navigation now aligns with primary navigation. The sidebar scroll reaches Agent team and Library.
- The actual favicon.svg URL serves the new two-polygon Flint mark. Direct transparent-SVG rendering is saved as iab-favicon.png.

Light/Flint appearance, Folders mode, unfiltered notes and the original Pricing Decision URL were restored. Temporary viewport overrides were reset. Task data was not changed.
